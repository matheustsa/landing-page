# TSA Tech Landing Page

Landing page desenvolvida com React, Vite, TypeScript e Tailwind CSS.

## Executando o Projeto

**Pré-requisitos:** Node.js

1. Instalar dependências:
   ```bash
   npm install
   ```
2. Iniciar o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
